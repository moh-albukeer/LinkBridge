# دليل استكشاف الأخطاء وإصلاحها ومتطلبات الشبكة وBluetooth

## 1. مشاكل الاتصال عبر Wi-Fi المحلي (عزل الأجهزة Client/AP Isolation)

- **المشكلة**: الجهازان متصلان بنفس شبكة Wi-Fi، لكن يفشل الاتصال المباشر أو لا يظهر الجهاز في الاكتشاف التلقائي.
- **السبب**: بعض أجهزة الراوتر (خصوصًا الشبكات العامة أو شبكات الضيوف) تفعّل ميزة **AP / Client Isolation** التي تمنع الأجهزة المتصلة من التخاطب المباشر، أو يمنع جدار الحماية (Windows Firewall) المنفذ `48520`.
- **الحل البديل الموثوق**:
  1. **تفعيل نقطة اتصال الهاتف (Wi-Fi Hotspot)**: شغّل نقطة الاتصال على هاتف Android ووصّل اللابتوب بها مباشرة (يعمل النقل محليًا بأقصى سرعة حتى لو كانت بيانات الهاتف مغلقة ولا يوجد إنترنت).
  2. **إدخال العنوان يدويًا أو مسح QR**: انسخ عنوان `IP:Port` المعروض في واجهة Windows وأدخله يدويًا في تطبيق الهاتف.
  3. **السماح بالمنفذ في جدار حماية Windows**: تأكد من السماح لتطبيق Python / LinkBridge بالاستماع على الشبكة الخاصة (Private Network) للمنفذ TCP `48520`.
  4. **الانتقال إلى مسار Bluetooth RFCOMM** للنصوص والملفات الصغيرة.

## 2. متطلبات وإعدادات Bluetooth على Windows 10/11 وAndroid 9+

- **المتطلبات على Windows**:
  - وجود محول Bluetooth يدعم **Bluetooth Classic (RFCOMM / SPP)** وتعريفات مفعّلة في Windows 10 أو Windows 11.
  - نسخة Python قياسية تدعم `socket.AF_BLUETOOTH` و`socket.BTPROTO_RFCOMM` (مدعومة افتراضيًا في إصدارات Python الرسمية لنظام Windows 3.9+).
- **خطوات الربط عبر Bluetooth**:
  1. افتح إعدادات Bluetooth في Windows وAndroid وأكمل اقتران الجهازين على مستوى النظام أولًا (System Pairing).
  2. افتح LinkBridge على الجهازين واختر المسار **`Bluetooth Classic (RFCOMM)`**.
  3. أدخل عنوان MAC الخاص بالبلوتوث أو اختر الجهاز من قائمة الأجهزة المقترنة، ثم أكمل مصادقة LinkBridge (رمز PIN في المرة الأولى).
- **ملاحظة الأداء**: معدل النقل عبر Bluetooth Classic RFCOMM يتراوح عادةً بين `100 KB/s` و`250 KB/s`؛ لذا يفضّل دائمًا استخدام **Wi-Fi** أو **نقطة اتصال الهاتف** عند نقل الملفات الكبيرة.

## 3. قيود الحافظة على Android 9 وما بعده

- إذا لاحظت توقف المزامنة التلقائية للحافظة في الخلفية بسبب قيود توفير البطارية في الهاتف، استخدم:
  - **مشاركة النظام (Share -> إرسال إلى الكمبيوتر عبر LinkBridge)** من داخل أي متصفح أو تطبيق ملاحظات.
  - أو **إشعار الإرسال السريع** أو **زر إرسال محتوى الحافظة الحالي الآن** داخل التطبيق.
